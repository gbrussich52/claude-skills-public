# Agent Skill Forge

**The universal standard and meta-skill for building production-grade, portable Agent Skills that work across Grok, Claude Code, and Codex-style autonomous agents.**

Forge skills that turn tribal knowledge and repetitive agent labor into **permanent, composable infrastructure**.

> "The best engineers spend time automating their own work... In the age of agents, this becomes even more important. Moving things to code [or skills] automates entire classes of issues forever. Every team should be writing the CLAUDE.md's, REVIEW.md's, skills, and docs that enable agents to productively work in their codebase with zero additional context."  
> — Boris Cherny, Claude Code

## Why This Exists

Current agent workflows suffer from three fatal problems:

1. **One-off toil**: Agents solve the same class of problem repeatedly with expensive tokens instead of encoding the solution permanently.
2. **Context & knowledge debt**: Critical domain knowledge lives only in human heads or scattered chats, blocking new contributors and reliable agent performance.
3. **Platform fragmentation**: Skills built for Grok don't transfer to Claude Code or advanced autonomous setups (Codex + NeMo-style workflows). MCP-powered dynamic artifacts are even harder to get right.

**Agent Skill Forge** solves all three with a single, rigorous specification + meta-skill that produces skills designed for:

- **Grok** skill system (native directory + SKILL.md format)
- **Claude Code** (CLAUDE.md patterns, MCP connector declarations for live Artifacts, project skills)
- **Codex / NVIDIA-style autonomous agents** ( `./skills/` layout, `/goal` invocation, long-running campaign support with memory + etiquette + autoresearch primitives)
- **Pi / OpenClaw-style minimal harnesses** (focused `.md` files with clean extension points the harness can load and evolve)

## The Vision: Skills as Infrastructure

Inspired by:
- Boris Cherny's automation philosophy (lint rules → skills + structured docs)
- NVIDIA's modular **skills** (brev-etiquette, session-memory, autoresearch) that let agents run complex multi-hour RL research campaigns
- Anthropic's **Model Context Protocol (MCP)** — turning static Artifacts into personalized, live, permissioned applications

The highest-leverage move in 2026 is **encoding domain knowledge and workflows as executable infrastructure** so that both humans *and* agents inherit superpowers on day one.

## What Makes a Skill "Forge-Worthy"?

A skill created with Agent Skill Forge is:

- **Portable** across major agent platforms
- **Robust for long-running work** (includes session memory, hygiene/etiquette, autoresearch campaign management, self-verification)
- **MCP-native** when relevant (for dynamic Claude Artifacts)
- **Self-improving** (designed to capture learnings back into the skill)
- **GitHub-native** (comes with excellent README, examples, and adoption path)
- **Composable** (small, focused, with clear `depends_on` relationships)

## Quick Start

### 1. For Grok Users

```bash
# The skill is already available in your environment
# Just describe what you need:
"Use agent-skill-forge to create a robust skill for multi-step business acquisition due diligence with financial modeling and LOI generation that works in both Grok and Claude Code"
```

### 2. For Claude Code Users

Drop the generated `my-skill/SKILL.md` (or a converted `skills/my-skill.md`) into your repo and reference it in your `CLAUDE.md` or project instructions. For Artifacts, include the MCP connector declarations generated by the skill.

### 3. For Autonomous / Codex-style Agents

Place skills in `./skills/` or `./agent-skills/`. Invoke with:
> "Use the my-skill skill under ./skills. [Clear goal + success criteria + time budget]"

## Core Primitives (Included in Every Forge Skill)

Every skill you generate includes battle-tested patterns for:

- **Session Memory & State Persistence** — Structured ledgers and state files so 6-hour campaigns don't drift
- **Etiquette & Hygiene** — Clean artifacts, centralized outputs, secret hygiene, resource cleanup
- **Autoresearch Campaign Orchestration** — Goals, hypotheses, baselines, experiment ledgers, stop conditions, branching, rich human handoff summaries
- **Self-Verification Loops** — Built-in critique steps after major actions
- **Self-Improvement & Documentation Sync** — Capture heavy-steering moments into an improvements ledger, run periodic retrospectives, and keep `SKILL.md` and `README.md` in lockstep
- **MCP Integration** — Proper declaration and usage patterns for live, viewer-permissioned data in Claude Artifacts
- **Domain Knowledge Extraction** — Turn Slack threads, code reviews, and "how we do things here" into permanent skills + `AGENTS.md` + `CLAUDE.md` + `REVIEW.md`

## The Universal Layout

```
my-skill/
├── SKILL.md                 # The heart — frontmatter + imperative instructions
├── README.md                # Human story, quickstart, philosophy (critical for stars)
├── scripts/                 # Deterministic executables
├── references/              # Long-form docs & templates
├── assets/                  # Reusable templates & boilerplate
├── examples/                # Working traces and mini-repos
├── compatibility/           # Platform-specific notes (grok.md, claude.md, codex.md)
└── tests/                   # Validation harness
```

## Philosophy in Depth

The best automation has always been **infrastructure**, not one-off scripts.

In the agent era this scales dramatically:
- A lint rule catches a class of bugs forever.
- A skill + `CLAUDE.md` + `REVIEW.md` lets agents (and new humans) operate at the level of your best engineer from minute one.
- MCP turns one shared Artifact into a personalized dashboard for every viewer using *their* data and permissions.

Agent Skill Forge makes this systematic and portable.
